Contributions to the ContentLib codebase are at the heart of what sets this API apart from similar solutions.
It is a core philosophy of ContentLib to be as much developed by the community as it is utilized by it. Every
contribution, no matter how small, helps improve the tool for everyone.

This section of the documentation is designed to make contributing as straightforward as possible while maintaining a
consistent, concise, and high-quality standard.


### **Why Contribute?**
- Be part of a growing community shaping the future of Lethal Company modding.
- Gain experience and recognition for contributing to an open-source project.
- Help create a more powerful, versatile, and accessible API for everyone.
- Help to ensure quick turnaround times on API patches when major game updates are released. 

### **What This Section Covers**
- **Commit Formatting:** Learn how to structure your commit messages for clarity and consistency.
- **Documenting Code:** Ensure your contributions are well-documented and easy to understand for future developers.
- **Interfaces and Implementations:** Understand, and be able to implement,ContentLib's Interface centered structure.
- **Writing Articles:** Guidance on how to structure documentation Articles, to ensure the continued quality of the 
ContentLib Docs.

### **How to Get Started**
1. Familiarize yourself with this contributing guide and the project’s overall documentation.
2. Review the repository for open issues or areas where you can add value.
3. Follow the guidelines in each section of this document to ensure your contributions align with the project’s
standards.
4. Don’t hesitate to ask questions or seek help from the community if needed.

Together, we can make ContentLib a more robust and versatile tool for the modding community. Thank you for being a part
of this journey!
